# SVG accessibility checklist

- [ ] Informative standalone SVG has `role="img"`.
- [ ] A concise `<title>` describes the purpose.
- [ ] A `<desc>` explains complex relationships.
- [ ] Title and description IDs are unique and linked by `aria-labelledby`.
- [ ] Text has sufficient contrast.
- [ ] Color is not the only signal for state or relationship.
- [ ] Text remains readable at intended display size.
- [ ] Decorative graphics are hidden from assistive technology where appropriate.
- [ ] Interactive controls are keyboard reachable and named.
- [ ] Focus is visible for interactive elements.
- [ ] Reading order follows the diagram's logical structure.
