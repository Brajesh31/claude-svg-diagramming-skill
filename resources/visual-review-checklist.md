# SVG visual review checklist

## Composition
- [ ] One clear focal point.
- [ ] Obvious reading order.
- [ ] Related elements grouped.
- [ ] Consistent alignment and spacing.
- [ ] Connectors avoid labels and unnecessary crossings.

## Typography
- [ ] Labels are concise and readable.
- [ ] Equivalent labels share styles.
- [ ] No clipped or overlapping text.
- [ ] Font stack has sensible fallbacks.

## Semantics
- [ ] Arrow direction is explicit.
- [ ] Relationships are labeled when needed.
- [ ] Boundaries and group labels are meaningful.
- [ ] Status is not communicated only by color.

## Delivery
- [ ] SVG opens in a modern browser.
- [ ] Dimensions and viewBox are intentional.
- [ ] No unexpected remote assets or embedded scripts.
- [ ] Structural validator passes.
